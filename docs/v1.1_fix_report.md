| 设计承诺 | 修复前实现 | 修复后实现 |

## 4. 数学机制审查（修复后）

### 4.1 损失与梯度

真实实现（`TSIL-main/src/model_backbone_phitp.py:97`，`WeightedMSELoss`）：

```text
L = (1/B) Σ_i e_i (M e)_i,   M = τ̂ I + (1−τ̂) P,   τ̂ = σ(α)
∂L/∂α = σ'(α) · (1/B) · eᵀ(I − P)e
```

当 `P` 半正定且 `λmax(P) ≤ 1` 时，`I−P` 半正定，故 `∂L/∂α ≥ 0`。这不是数值偶然，而是参数化结构决定的单向棘轮：梯度下降只会压低 α，τ̂→0，目标漂移到秩 1 项 `(φᵀe)²/‖φ‖²`。

### 4.2 τ 的处理（D-12）

- `QniverseModel` 新增 `tau_mode ∈ {learned, fixed}` 与 `fixed_tau`；
- `fixed` 模式下 τ̂ 为常量，**不进入计算图**（`_tau()` 返回 `requires_grad=False` 的张量）；
- 三份 TSIL 配置显式设置 `tau_mode: fixed`、`fixed_tau: 0.5`；
- 训练记录 `tau_mode`、`fixed_tau`、每个 epoch 的 `tau_history`；
- 上游 `TSIL-main/train.py` 等直接调用方仍默认 `learned`，保持历史行为。

必须如实表述：V1.1 的 TSIL 科学运行使用**固定 τ=0.5 的超参数**，不是“学习到的 MSE/P 权衡”。换 τ 可能改变结论，尚未做敏感性分析。

### 4.3 φ/P 构造与归一化

- 原生/DSL 谓词：`P = φφᵀ/‖φ‖²`，`trace(P)=1`，`λmax(P)=1`；
- 组合谓词：`p_mix` 按迹归一化（D-13 同步修复）；
- cross-correlation：`P=(corr+1)/2` 后按迹归一化；
- 退化 φ：返回全零，`P=0`，probe 在任何训练前拒绝。

数值证据（`repro_I_crosscorr_scale.py`）：

```text
修复前: trace 1.8879708051681519  λmax 0.9743107557296753
修复后: trace 0.9999998807907104  λmax 0.5160624384880066
eᵀ(I−P)e 在随机 e 上: 0.0127（≥0）
```

### 4.4 已确认的退化机制

1. 常数 φ（或常数相关矩阵）→ P 为均匀矩阵；旧 probe 因包含对角零元而误判 `off_std≈0.0019`。修复后严格非对角 `max/range` 判定为退化。
2. τ→1 → MSE 项消失，目标只剩秩 1 投影；固定 τ 阻止了训练中的漂移，但 `τ=0.5` 仍是人为选择。
3. `P` 的迹归一是跨谓词比较的前提；修复前 cross-corr 的 trace≈1.888 使 P 项尺度不可比。

### 4.5 尚未验证的研究假设

- “谓词带来的 IC 提升来自谓词结构，而不是固定 τ 或 P 尺度” —— 未在真实 TSIL 上做 τ/尺度消融；
- “λmax(P)≤1 在所有候选描述符上都成立” —— 仅在测试的 native/DSL/cross-corr 路径上数值检查；
- “early-stop 与报告分离后，confirmation 仍能检出真实效应” —— 只有合成数据验证；
- “固定 τ 后 LUSI 仍优于 plain MSE” —— 无真实结果。

## 8. 下一阶段研究建议

### 8.1 必须修复的工程问题

1. 在 GPU 空闲且获得批准后，执行真实 **Smoke A**：1 候选 + MSE baseline + Φ_ones，1 seed / 1 fold / 最低预算；校验 loss/grad/pred 有限、NPZ 可读、指标可重算。
2. Smoke A 通过后执行 **Smoke B**：1 round / 2–3 候选 / 3 seeds；验证去重、筛选、反馈、freeze、确认与证据落库。
3. 增加跨进程崩溃恢复测试（真实 worker 被杀后 exact retry），而不是仅同进程模拟。
4. 为 `full_content_manifest` 的非 verify 调用方明确文档化“size+mtime 缓存假设”，或统一改为 content-addressed。

### 8.2 必须验证的数学问题

1. 固定 τ 的敏感性：τ ∈ {0.25, 0.5, 0.75} 下候选与 baseline 的差异是否稳定。
2. P 的谱性质：所有候选（含组合/外生）是否满足 `λmax(P)≤1`、`trace(P)=1`；probe 应记录完整谱。
3. LUSI 目标在 τ 固定后是否仍有意义：与 plain MSE 的差异来源是谓词项还是优化噪声。
4. 若要恢复“学习的权衡”，需重新参数化（如对两项分别学习正权重并加约束），不能用当前 `σ(α)` 形式。

### 8.3 必须改进的实验协议

1. **预注册**搜索策略（阈值、top_k、folds、τ），并纳入 protocol_hash（已实现，需在真实 run 中执行）。
2. screen/validation/confirmation/holdout 严格分离（已实现，需用真实 run 验证）。
3. 每个候选的 family-wise 推断必须以实际选择规则为条件；不能把 `validated` 当独立确认。
4. 历史 holdout 已消费，任何“V1.1 新 final”都必须使用新的、未被消费的数据或明确标注为 exploratory。

### 8.4 值得进一步研究的算法方向

1. 谓词有效性的事前判据（而非事后 IC 筛选）：谱性质、稳定性、与残差的相关结构。
2. 可双向学习的 MSE/P 权重（带约束/正则），替代单向 α。
3. 组合谓词的尺度不变性（迹归一化后）与多重检验校准。
4. 将 early-stop 与报告分离后的 confirmation 设计做成可证明的选择后推断流程。

### 8.5 目前不能成立的科研主张

- ❌ “V1.1 TSIL 已通过真实集成” —— 未执行 Smoke A/B。
- ❌ “历史 final 的候选在 V1.1 协议下得到独立确认” —— 历史流程存在选择泄漏。
- ❌ “LUSI 学习到了 MSE 与谓词项的最优权衡” —— α 单向棘轮；V1.1 使用固定 τ。
- ❌ “某个谓词显著提升 IC” —— 历史证据受 screen/validation 重叠与 freeze 方向影响，且未重算。
- ❌ “129 个测试通过 = 科研结论成立” —— 测试只证明代码路径，不证明真实数据上的效应。

### 8.6 优先级判断

**应先研究谓词有效性与损失机制，再扩展候选搜索。** 当前最稀缺的不是候选数量，而是“在无选择泄漏、固定 τ、可重算预测的前提下，某个谓词是否稳定优于 baseline”的证据。在真实 Smoke A/B 完成前，扩大搜索规模只会增加多重检验与选择偏差。
