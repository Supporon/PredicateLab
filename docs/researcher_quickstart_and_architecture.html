完成场景 A1 的 30 行代码改动并准备好 configs/tabular_my_study.yaml 后，按顺序执行以下 4 步：

核心防泄漏保障：所有谓词参数（如分位数阈值 threshold、中位数与四分位距 sigmoid、标准化均值方差 interaction）均在 fit_transform(desc, X_train, X_other) 中严格仅使用当前折的 X_train 拟合。
终端执行命令序列（Tabular 域）
cd /home/zhengzengrong/PredicateLab/Predicate_Lab_v1.1
export PY=/home/zhengzengrong/miniconda3/envs/predicatelab/bin/python

# 1. 验证数据完整性、缺失值与分层折划分（0 账本消耗）
$PY -m predicatelab.cli validate-config --config configs/tabular_my_study.yaml

# 2. 启动多轮谓词检索（自动完成 Probe -> Screen -> Full Validation -> 累积 BH FDR）
$PY -m predicatelab.cli discover --config configs/tabular_my_study.yaml \
    --rounds 3 --run-id study_tab_01

# 3. 查看检索证据表与生成 Markdown/JSON 报告
$PY -m predicatelab.cli evidence --config configs/tabular_my_study.yaml --run-id study_tab_01
$PY -m predicatelab.cli report   --config configs/tabular_my_study.yaml --run-id study_tab_01

# 4. 冻结候选族并在确认折上做独立确认（注意：每个确认折仅可独立确认一次）
$PY -m predicatelab.cli freeze-family --config configs/tabular_my_study.yaml \
    --run-id study_tab_01 --top-k 3
$PY -m predicatelab.cli confirm --config configs/tabular_my_study.yaml \
    --run-id study_tab_01

# 5. 对通过确认的唯一最优谓词执行 20% 冻结 Holdout 终审（一次性操作！）
$PY -m predicatelab.cli finalize --config configs/tabular_my_study.yaml \
    --run-id study_tab_01 --candidate-id cand_xxxxxx
赛道 B：在 TSIL 上设计并探索新的时序谓词

TSIL 的统计不变损失为 L = τ̂ · eᵀIe + τ · eᵀPe。每次编写新谓词后，先跑 5 秒 CPU 探针自检，通过后再启动 GPU 训练：

机制设计准则 (R05/R06)：默认训练采用 shuffle: true, batch_size: 800，单个 batch 跨越约 2 年交易日（同日仅约 2 只股票）。请设计单样本时序特征算子（在 dsl.py:raw_phi 中提取每个样本自身的 [T, F] 时序特征），避免使用跨样本均值伪造“当日市场指数”。
Step 1：5 秒 CPU 探针快速自检（免跑 GPU 检验 5 项数学门控）
PYTHONPATH=/home/zhengzengrong/PredicateLab/Predicate_Lab_v1.1 \
/home/zhengzengrong/miniconda3/envs/predicatelab/bin/python -c '
import yaml
from predicatelab.domains.tsil.adapter import TSILAdapter

cfg = yaml.safe_load(open("/home/zhengzengrong/PredicateLab/Predicate_Lab_v1.1/configs/tsil_lstm_smoke.yaml"))
cfg["run"]["artifacts_dir"] = "/home/zhengzengrong/PredicateLab/audit_20261107_credibility/tmpdata/tsil_smoke_verify_v2/artifacts"
adapter = TSILAdapter(cfg)
snap = adapter.snapshot(cfg)
f2022 = [f for f in adapter.build_protocol(cfg).folds if f.fold_id == "f2022"][0]

# 替换为你新写的算子描述符：
desc = {"family": "volatility", "params": {"window": 10}, "feature_slice": [0, 64]}
res = adapter.probe(desc, f2022, snap, cfg, "/tmp/probe_quickcheck")
print("PROBE OK:", res["ok"], "| REASON:", res["reason"])
print("CHECKS:", res.get("checks"))
'
